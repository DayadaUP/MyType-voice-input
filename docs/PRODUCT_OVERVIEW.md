# 产品概览

## 目标

MyType 希望把语音输入做成一个更接近键盘输入的桌面工作流工具：

- 启动快
- 反馈清晰
- 插入稳定
- 尽量不打断当前输入场景

## 当前公开版本范围

当前公开仓库聚焦 macOS 版本，主要包含：

- 语音录音与停止控制
- 本地识别、云端识别、混合识别
- 实时预览与最终文本插入
- 个人词库与语气词过滤
- API 配置与连通性测试
- 本地模型部署与管理

## 设计原则

- 默认不内置任何私人云端凭证
- 优先保证文本插入稳定性
- 对高频输入场景保持低打扰
- 本地模式和云端模式可以独立使用

## 隐私边界

- 仓库中不包含任何私人 API key
- 仓库中不包含本地模型文件与虚拟环境
- 仓库中不包含个人样本、测试日志、开发过程记录

## 平台范围

- 当前主实现：macOS
- 代码仓库公开内容：以 macOS 可运行源码为主
